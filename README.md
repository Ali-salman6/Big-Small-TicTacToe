# Big Small Tic Tac Toe Using Python GUI 🟦🟥

A unique twist on classic Tic Tac Toe built with Python and Tkinter. 
Supports Player vs Player and Player (PvP) vs Computer modes (PvC), and features "small" and "big" pieces with capture logic.

## Features
- PvP and PvC modes
- Selectable board size (3x3 to 10x10)
- Strategic "big piece" override system
- Score tracking and GUI interface
